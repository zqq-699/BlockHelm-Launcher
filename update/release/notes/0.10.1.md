# 正式版 0.10.1

## 新功能

- 新增 Java 深度搜索，可扫描本机磁盘。
- 新增语言设置为中文时，Mod 的中文名称显示与中文搜索。
- 新增 Mod 详情界面的 MC 百科跳转链接。
- 新增游戏设置的资源包、光影包和存档页面的在线安装入口。
- 新增资源中心数据包搜索与下载，支持从 Modrinth 和 CurseForge 下载数据包。
- 资源筛选按钮现在会显示已启用的筛选数量。
- 更新提示弹窗现在支持直接显示 Markdown 格式的更新日志。

## 问题修复

- 改善列表图标缩放时的锯齿问题。
- 修复启动器不同网络请求使用的 User-Agent 不一致问题，统一 User-Agent 为 BHL/{version}。
