# 正式版 0.11.1

## 新功能

- 新增下载源自动选择，可根据下载源的可用性和响应情况选择下载线路。
- 第三方登录所需的 authlib-injector 支持官方源和 BMCLAPI 镜像，并可在下载失败时使用已校验的本地缓存。

## 问题修复

- 修复部分 Forge 和 NeoForge 安装过程中游戏下载、映射文件下载或生成文件校验失败的问题。
- 修复部分下载在服务器不支持分段请求、下载中断或响应异常时无法正常恢复的问题。
- 修复 Forge 版本列表并发查询时，空结果可能覆盖已有版本列表的问题。
- 修复个别实例目录或文件暂时无法读取时，可能影响其他实例显示或启动的问题。
- 修复实例目录被外部工具移动、更名或替换后，设置和资源操作可能指向错误实例的问题。

## 优化改进

- 优化游戏下载调度、慢速下载恢复和下载源切换，提高复杂网络环境下的下载稳定性。
- 改进游戏下载和加载器安装进度显示，便于了解当前安装阶段。
- 改进下载与安装失败日志，提供更完整的排查信息。
- 更新 MC 百科 Mod 中文名称和相关链接数据。

## 兼容性与迁移

- 升级后，旧版本的下载源设置会一次性迁移为自动选择；如需固定使用官方源或 BMCLAPI，可在设置中重新选择。
- 实例设置会迁移到基于实例目录的识别方式，以改善与外部启动器和文件操作的兼容性。
