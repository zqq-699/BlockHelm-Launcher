# 下载与安装失败诊断

下载错误详情默认写入 `BHL/log/bhl-*.log`，无需提前开启诊断模式。启用诊断模式会增加正常传输和缓存明细，不是捕获失败原因的前提。自动更新接力进程仍写入 `updater-*.log`。

## 关联与阅读顺序

- `LogSession` / `LogSequence` 标识进程会话及事件序号；轮转文件首行记录前一文件名。
- `OperationId` 标识安装、导入、修复或下载操作。前台下载任务的取消记录使用对应操作标识。
- `BranchId` 区分整合包的 `PackFiles` 和 `LoaderInstall`；`FileId`、`RequestId` 区分并行文件与请求。
- `ParentRequestId` 关联下载执行器请求与各次 HTTP 传输。异常链的 `CauseFailureId` 与分支的 `PrimaryFailureId` 使用同一套标识。
- `Stage` 指出安装器下载、依赖准备、Java 进程、产物校验、版本识别、最终补齐或发布阶段。长阶段每 30 秒输出状态。
- 查找首个故障及其 `FailureId`，再检查对应资源的 HTTP、重试、完整性或进程输出记录。`PrimaryFailureId` 解释整合包其他分支的连带取消，不能把所有 `Canceled` 都当成独立下载故障。

## 覆盖入口

| 入口 | 诊断接入 |
|---|---|
| 原版、Java、Fabric、Quilt、Forge、NeoForge、资源索引 | 统一执行器、HTTP 传输、CmlLib 文件适配器 |
| Mod、整合包、资源包、光影、数据包和地图 | 文件解析与下载、完整性检查、原异常传递 |
| 启动修复和服务端部署 | 下载批次、安装器、产物校验 |
| CurseForge / Modrinth 元数据与图片缓存 | 独立 HTTP 观察器或统一执行器 |
| 自定义文件、自更新、Terracotta、authlib-injector | 保留各自传输和安全策略，记录失败阶段及校验详情 |
| 头像、皮肤、披风和 WPF 图片 | 下载、缓存回退及下载/解码失败；WPF 未提供的 HTTP 状态标记为不可用 |

## 关键证据

- 网络：方法、源、主机、响应状态、重定向、超时、重试等待，以及失败时已接收的字节。`NetworkAttempts` 统计实际 HTTP 发送，包含没有收到正文的失败和重定向请求；分段尝试另有分段 ID 和范围。
- 等待：`DownloadSessionAcquire` 表示等待文件会话/锁，`Admission` 表示等待网络并发准入，二者不会被误记成传输失败。独立 HTTP 客户端只有在异常链证明超时时才标记 `InternalTimeout`，否则使用 `NonCallerCancellation`。
- 文件：缺失、大小不符、哈希不符分别记录；包含预期/实际大小、哈希算法、预期/实际哈希，以及校验模式。没有执行的哈希检查标记为 `NotChecked`。
- 安装器：实际 Java 路径、版本、架构和来源，安装模式、PID、退出码、持续脱敏的 stdout/stderr。非零退出包含各流最后 100 行安全输出。
- 取消：前台取消源区分 `User` 和 `ApplicationExit`；整合包记录 `UpstreamFailure` 与首个故障；被成功备用请求取代的请求标记 `SupersededRequest`。其他调用方取消使用 `CallerCancellation`，不猜测来源。
- 异常：安全原因码、白名单参数、异常链及聚合异常各分支，包含可用的方法和行号，不包含本机源码目录。
- 本地文件：已知 Windows 错误码区分 `DiskFull`、`AccessDenied`、`SharingViolation`、文件/目录不存在等原因，不依赖原始异常消息。

## 安全与保留

不输出任意异常的原始消息、`Exception.Data`、认证响应、请求正文、完整请求头或环境变量。URL 路径及查询参数继续脱敏，通过资源坐标、文件名和项目/文件 ID 识别资源。

安装器 stdout/stderr 各自维护流式脱敏状态。单行最多 16 KiB；超过上限时明确标记，并保守抑制该流后续内容以防跨行凭据泄漏。

流式脱敏同时保护跨行的凭据键和值，以及 `proxyPassword`、`keyStorePassword`、`secretAccessKey` 等带前缀的参数。安装器只读取继承环境中的 `JAVA_TOOL_OPTIONS`、`_JAVA_OPTIONS` 和 `JDK_JAVA_OPTIONS` 三个指定值，作为输出脱敏的已知敏感值；不记录这些值，不枚举其他环境变量，也不改变 Java 的继承行为。

异常诊断总量有 64 Ki 字符预算，单个动态字段最多 16 Ki 字符；超大字段整段省略并标记截断，不先截断可能包含凭据的文本。历史尝试保留安全原因摘要而不重复整套栈。诊断字段投影发生异常时，仍保留原故障类型、故障 ID、错误码及可用调用栈。

沿用单文件 20 MiB、最多 20 个启动器日志、30 天的保留策略。反馈长任务时应保留同一会话的轮转文件。日志无法追溯补回旧版本已经丢弃的异常详情。

## 验证

`DownloadDiagnosticsTests` 使用真实主日志配置和格式器验证默认级别失败、关联隔离、轮转、脱敏、安装器启动/非零退出、安装后校验及并行取消；其余下载、续传、分段、安装、修复及安全行为由现有测试覆盖。

复查增加了正文预期/实际长度、首字节与正文停滞、独立客户端内部超时、磁盘/权限/占用、无效安装器与配置、取消回调异常、大诊断字段，以及经过业务异常包装后的真实尝试次数和换源判断。

共享发布冲突保留比较时已经得到的大小和 SHA-1，不为日志重新读取大文件；大小不同而未计算哈希时明确记录 `NotChecked`。回归测试同时验证冲突不会覆盖用户已有文件。

最终安全复查通过真实主日志和受控子进程验证继承 JVM 选项在连续输出及失败尾部摘要中均被脱敏，且其后的安装器诊断仍可见。跨行凭据测试覆盖空行、引号、命令参数和 Authorization/Bearer 的键值分离。

追加审查补齐了 Fabric API / QSL 元数据、Modrinth 批量图标和整合包元数据、CurseForge JSON 读取以及 MCRES 请求的诊断。独立 HTTP 响应与后续 JSON 解析使用同一请求上下文；解析失败包含预期格式、内容类型和 HTTP 状态，保留原有 JSON 解析方式、请求完成模式、重试和源选择策略。

Authorization 输出包含 Negotiate、Digest、NTLM 等方案时，隐藏完整的未加引号值，并保护分行的方案名与凭据。缺失 API Key、真实 HTTP 拒绝和成功后的空版本结果分别记录，不输出 API Key 或响应正文。

清理版本目录时的枚举错误单独记录，不覆盖安装原异常；共享文件临时发布、修复工作区、authlib-injector 和 Terracotta 的清理失败默认可见。测试在独立临时目录中注入目录枚举权限拒绝，验证原始安装异常仍被保留。整合包导入、资源完整性和无兼容版本异常输出结构化业务原因。

生产调用链逐项核对时修复了 `FinalVersionInstaller` 的 logger 漏传：Forge、NeoForge 和整合包安装器均把现有 logger 传给最终文件补齐阶段及其 CmlLib 元数据/文件下载适配器，避免仅有外层阶段失败而没有底层请求证据。

## 合并审查范围

| 方面 | 核查与证据 |
|---|---|
| 默认日志 | 使用真实文件 sink 和格式器，关闭诊断模式，核对 HTTP/解析/校验/Java/并行取消故障 |
| 下载行为 | 复查源优先级、重试、范围请求、续传、提交与共享文件保护，运行既有下载和安装回归 |
| 安全 | 任意异常消息及 Data 不输出；凭据、签名 URL、跨行/跨块/超长进程输出及继承 JVM 选项回归 |
| 生产接入 | 核对 DI、Logger 传递、CmlLib 适配器、独立元数据和图片入口，清理失败单独记录 |
| 并发 | 操作/文件/请求上下文隔离，首故障与连带取消关联，清理异常不能替换业务异常 |
| 架构 | 日志契约位于 Application，网络与文件操作仍在 Infrastructure，View 只观察 WPF 图片失败 |
| 保留 | 真实日志轮转测试；生产 20 MiB / 20 文件 / 30 天策略不变 |

这些检查支持代码合并判断，不代表完成真实国内网络、代理组合及各版本安装器的端到端验收，也不能保证任意外部安装器输出中的无标签敏感文本都可被规则识别。

## 能判断到什么程度

上述验证保证的是对应故障类别的默认日志包含可追踪的阶段、资源身份、原因码和证据，不是只记录测试中的异常类型。外部 SDK 的全新异常仍安全记录类型、错误码和栈，不会为获取原始消息而放开认证数据。

日志能指出 DNS、TLS、HTTP 拒绝、传输中断、Java 进程、产物校验或本地文件操作等直接失败点；仅凭客户端日志不能证明运营商、代理、远端服务内部的最终原因。进程被强制终止、断电或日志所在磁盘无法写入，也可能没有完整终结记录。

正常验证命令为 `dotnet build Launcher.sln` 和 `dotnet test Launcher.sln`。若正在运行的启动器锁定默认输出，可为二者追加 `-m:1 -p:OutputPath=bin/download-diagnostics/` 使用独立目录。
